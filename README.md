# 僵尸毁灭工程服务器租用：4人开黑到20人长期世界，配置档位、月付价格和一键开服流程一次说清

约好四个人周末开一局《僵尸毁灭工程》，结果发现房主的电脑一关机，世界就停在原地；第二天想接着玩，存档还坏了。这个场景几乎每个 PZ 联机群都遇到过。租一台服务器能解决它，但租之前你得先搞清楚 PZ 到底吃多少资源——因为很多人是拿《我的世界》的经验去挑配置的，然后发现不够用。

## PZ 服务端到底吃什么，和 MC 不是一回事

PZ 服务端跑在 Java 上，主模拟循环基本单线程。这意味着核心数不是第一优先级，单核主频和 IPC 才是——一台高主频的四核机，跑 PZ 往往比核心数更多但主频低的老 Xeon 更顺。

内存是另一回事，而且比大多数游戏难伺候：

- 服务端本体起步就要 2GB，实际上 4GB 才算稳；每个在线玩家再叠加 150–400MB，模组和大图层层往上加。
- 面向 10 人以内的服务器，常见建议是 2–4 vCPU + 4–8GB；10–50 人则要 4 核以上、8GB 以上。
- 有主机商直接把 8GB 写成 PZ 的最低门槛，模组多或 8 人以上建议 16GB；也有评测认为 8–10GB 才是健康多人服的真实底线，从 Build 41 换到 Build 42 大约要多留 2–4GB。

把这些数字凑起来就是一个结论：**4GB 内存对 PZ 只够两三个人玩原版，想长期开、带点模组，8GB 是起步线。** 只要看到配置表上写着「2核4G 可承载 12 人」，先确认那是不是以 MC 为基准算出来的。PZ 的账不一样。

## 为什么最后大多数人还是选择租

自己的电脑开服，问题不在于能不能开，而在于它什么时候掉链子。你在打游戏时它在干活，你关机上床后世界就停了；Windows 半夜自动更新重启；家里上行带宽被别的设备一挤，远端玩家开始瞬移。PZ 的世界状态又脆，硬崩一次可能直接损坏区块，几十小时的进度说没就没。

租服务器买的是三件事：24 小时在线、和别人家的设备互不抢资源、以及一个不用自己盯着的基础防护。剩下要挑的，就是配置和价格。

## 雨云游戏云：产品形态和计费方式

雨云是 2018 年成立的一家国产云服务商，产品线包括云服务器、游戏云、裸金属物理机、虚拟主机、对象存储等，游戏云是它面向开服场景的主力产品。

游戏云本身分两种形态。一种是**游戏云 VPS**：高主频 CPU、BGP 网络带防御、全系 NVMe 固态、附赠 30G 系统盘 + 20G 数据盘、200M 下行带宽，允许自定义开放 15 个端口，支持 Windows 和 Linux，并且提供一批预装软件。开 PZ 用不上太多端口，15 个足够一个服加几个附属服务。

另一种是**自研游戏面板**：支持 CPU 升降级、一键开服、可视化管理、备份和 MySQL，网页操作加 SFTP，适合没有命令行基础的单端服主。这里有个务实的提醒：面板对主流整合类游戏通常有现成模板，PZ 属于 Steam 侧的产品，下单前先去控制台确认有没有 PZ 模板；没有的话就走游戏云 VPS 自己部署，反正步骤也不复杂，后面会写。

计费上雨云有两种模式，这点对开服的人挺重要：

- **固定计费**，就是常规的按月付租金，费用好预测。
- **动态计费**，底价月租较低，然后按每天的 CPU 超额使用率单独日结。官方把 CPU 使用率基准定在 20%，低于这个值不产生额外费用，超出部分才计「电费」，内存等其他硬件不参与。对那种晚上开几小时、白天没人的服，这种模式通常更省；如果是 24 小时满负荷的长期大服，固定计费更好算账。

机房方面，雨云在国内有镇江、宁波、温州等多个节点。镇江走 BGP 线路，官方论坛提到该地区针对 Steam 做过优化，海外朋友也能勉强进来玩；宁波机型标的是 100G 高防，适合公开宣传、容易被盯上的服。

## 从零把 PZ 服务端跑起来

不管选 VPS 还是面板，PZ 的服务端部署逻辑是一样的，差别只在谁去执行：

1. **装环境**。Linux 选 Ubuntu 22.04 或 Debian，Windows 直接远程桌面连上去。需要能跑 32 位程序的环境，SteamCMD 依赖里包含 i386 相关包。
2. **用 SteamCMD 拉服务端**。PZ 专用服务端的 app id 是 **380870**，登录匿名账号即可，`force_install_dir` 指定到一个独立目录，后面所有配置都在那个目录里。
3. **改配置**。`MaxPlayers` 别留在默认的 32，按你买的档位改，比如 8 或 16，让上限和内存匹配。`KeepPauseEmpty=true` 可以让没人在线时暂停世界模拟，省资源也省电费。
4. **给 JVM 内存参数**。启动脚本里的 `-Xms` / `-Xmx` 按机器可用内存的一半左右给，别一看买了 12G 就写 16G——分得太满反而会让 GC 拖慢服务端。
5. **放通端口**。服务端默认走 UDP 16261，在雨云控制台把对应端口加进放行列表，NAT 机型记得做端口转发。
6. **备份**。存档目录定期打包，或者利用雨云的备份和快照功能。PZ 存档出问题的时候，有没有备份就是「重开一局」和「删服」的区别。

面板用户把文件管理器和 SFTP 用起来就行，上传存档、改 ini、换模组都不需要命令行。

## 几个开服前常问的问题

**面板和 VPS 到底选哪个？**
你要开的只是一个 PZ 服，且愿意按教程走一遍 SteamCMD，选游戏云 VPS，可控性更高，Windows 和 Linux 都能用。面板的优势在省事和自带备份管理，适合同时对多个游戏开服、又不想碰命令行的场景。

**4核8G 能带多少人？**
原版加少量模组，6–10 人是个比较稳的区间。再往上加模组或者开地图扩展，内存是第一个撑不住的地方，这时候升级内存比升级 CPU 更有效。

**动态计费会不会反而更贵？**
看你服务器的作息。晚上开几小时、白天闲置的服，动态计费大概率更便宜；24 小时被人占满的长期服，固定计费的账单更好预测。

**开游戏服要备案吗？**
玩家连接用的是 IP 加端口直连，不经过域名解析，一般用不到备案流程。真正涉及备案的是拿服务器解析域名建站的情况。
